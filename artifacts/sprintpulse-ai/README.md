# SprintPulse AI service

This directory registers the Python Streamlit app at the project's root preview and published URL. The implementation remains in the repository root (`app.py`, `agents/`, `tools/`, `data/`, `reports/`, and `tests/`).

Python dependencies are defined in the root `pyproject.toml` and `uv.lock`. This service runs Streamlit directly; it does not use React or Vite.
